### ⚡ About Me

I am a **Software Engineer & Systems Architect** obsessed with extreme performance, low-level optimization, and scalable interactive worlds. Whether it's architecting cloud-native distributed backends capable of handling millions of concurrent requests or writing custom 3D rendering pipelines and physics interactions from scratch — I build systems that don't just work, they scale effortlessly.

* 🎮 **Game Engine & Graphics Architecture:** Designing complex 3D environments, custom shaders, procedural animations, and real-time multiplayer state synchronization (inspired by RAGE & modern AAA pipelines).
* 🌐 **High-Load Backend & Cloud Infrastructure:** Engineering fault-tolerant microservices, real-time telemetry, and low-latency network protocols suitable for enterprise scale.
* 🧠 **Core Philosophy:** Clean architecture, memory safety, algorithmic efficiency, and zero-overhead abstractions.
